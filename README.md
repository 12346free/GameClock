    # 🎮 Game Clock (游戏悬浮时钟)

    > **轻量、安全、美观的 Windows 游戏悬浮时钟**
    > 采用 Win32 GDI + QPainter 离屏渲染引擎，不注入/不 Hook/0 内存接触，完美兼容《赛博朋克 2077》等 DX12 / 独占全屏 /无边框窗口游戏。
  

    ---

    ### ✨ 亮点特性

    - 🛡️ **100% 反作弊安全**：纯系统级分层窗口，不修改任何内存，无惧 EAC / BattlEye / Vanguard 等反作弊。
    - 🎯 **强力游戏置顶**：原生兼容 DX11 / DX12 / Vulkan 游戏的全屏与无边框窗口模式。
    - 🎨 **Material Design 预设**：内置 10 种精美主题（Material Indigo/Teal/You Purple、赛博朋克、复古终端等）。
    - 🔒 **点击穿透与锁定**：快捷键一键锁定，开启窗口穿透，完全不干扰游戏按键与视角。

    ---

    ### 🎮 快捷操作

    | 功能 | 操作方式 |
    | :--- | :--- |
    | **移动位置** | 未锁定状态下，**左键拖拽** 悬浮窗 |
    | **打开设置** | 未锁定状态下 **右键点击** 悬浮窗，或 **双击托盘图标** |
    | **锁定/解锁** | 按 **`Ctrl + Alt + G`**（锁定后开启点击穿透） |
    | **快速换色** | 右键托盘图标 ➔ `快速换色` |
